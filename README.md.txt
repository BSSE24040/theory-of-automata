# Theory of Automata (SE304-T)

This repository contains Google Colab notebooks, practical activities, and implementations completed as part of the **Theory of Automata (SE304-T)** course in the BS Software Engineering program at Information Technology University (ITU), Lahore.

The repository documents practical work and experiments related to automata theory, formal languages, and computational models.

## Topics Covered

* **Python and Byte Pair Encoding (BPE):** Environment setup, experiments, and implementation.
* **Deterministic Finite Automata (DFA):** State transitions, transition tables, and string tracing.
* **Nondeterministic Finite Automata (NFA):** Nondeterminism, accepting paths, and language recognition.
* **Epsilon-NFA (ε-NFA):** Epsilon transitions and epsilon-closure calculations.
* **Subset Construction:** Conversion of NFA and ε-NFA into equivalent DFA.
* **Regular Languages:** Regular expressions, language operations, and closure properties.
* **Formal Languages:** Alphabets, strings, language notation, and related concepts.

## Repository Contents

The repository consists of Google Colab notebooks (`.ipynb`) containing relevant code, experiments, examples, outputs, and explanations.

Each notebook corresponds to an activity or topic and can be explored independently.

## Getting Started

You can explore the notebooks directly on GitHub or execute them using Google Colab.

1. Open the notebook you want to explore.
2. Click **Open in Colab**, if available, or download the notebook and upload it to Google Colab.
3. Review the explanations and code cells.
4. Run the cells in sequence to reproduce the experiments and results.

Some notebooks may require additional Python packages or environment configuration, which should be specified in the relevant notebook.
